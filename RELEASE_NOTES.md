# RAR NetCare 1.2.0

Windows adds profile-based usage statistics, daily charts, application attribution where Windows supplies records, configurable plan alerts, and mini meter appearance and units. The meter remembers its dragged position. Adapter selection supports multiple interfaces.

Speed tests chart measured throughput and HTTP latency, record loaded latency in history, and offer PNG export on Windows. Network information, saved wireless profiles and windowed processes have searchable detail views. Windows Settings and Task Manager handle system management actions.

The data plan uses traffic recorded by RAR NetCare while running. The Usage stats page queries Windows separately. Existing profiles and test history use their previous storage keys.
