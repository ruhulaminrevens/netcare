# Privacy policy

Effective date: 1 September 2026

RAR NetCare is designed to work without an account and without developer-operated telemetry.

## Data stored on the device

The app can store the following locally:

- speed-test results and timestamps;
- ISP, public IP, local IP, gateway, and selected test-server labels recorded with a result;
- a user-created network profile containing optional router, switch, server, and remote-host addresses;
- language and theme preferences.
- the last observed public IP, first-seen time, observation count, and whether an IP change has been detected.

This information remains in the app's local storage unless the user copies a report and shares it independently. Removing the app normally removes its local data. The History screen can also clear saved test results.

## Network requests

The default test makes HTTPS requests to `speed.cloudflare.com` to measure latency, download throughput, upload throughput, and obtain network metadata. The app also requests public-IP, ISP/ASN, and approximate IP-location metadata from `ipwho.is`. Test payloads are generated bytes and do not include personal files. DNS and reachability checks contact the selected DNS target, Cloudflare connectivity target, detected gateway, and only the custom addresses entered by the user.

Cloudflare and IPWhoIs process requests under their own terms and privacy policies. IP location is approximate and the app does not request GPS or Android precise-location permission. A future custom-backend setting can let operators use their own compatible server.

## Advertising, analytics, and sale of data

The app contains no advertisements, third-party analytics SDK, account system, or mechanism for selling user data. The project maintainer does not receive app history or custom network profiles.

## Permissions

- Internet access: required for speed and connectivity tests.
- Network and Wi-Fi state: used to show local network information when the operating system provides it.

The app does not request contacts, storage, camera, microphone, SMS, call-log, or precise-location permission.

## Contact

Use the public GitHub issue tracker for privacy questions that do not contain sensitive network details. Do not post public IP addresses, private infrastructure details, credentials, or diagnostic reports containing information you do not want to disclose.
