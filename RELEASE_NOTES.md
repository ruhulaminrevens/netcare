# Ruhul NetCare v1.0.0

First public release of the Windows and Android network diagnostic app.

## What is included

- Responsive Bengali/English interface with dark and light themes
- Quick, Balanced, and Deep internet speed tests
- Download, upload, ping, jitter, and request-loss results
- ISP, public IP, local IP, gateway, and DNS information
- Router, switch, LAN server, and remote/Tailscale reachability profiles
- Local-only history with copyable JSON reports
- Optional PHP 8+ shared-hosting test-point package
- Windows installer, Windows portable build, Android APK, and SHA-256 checksums

## Download notes

- Windows may show a SmartScreen warning because the installer is not backed by a paid Authenticode certificate.
- Android requires **Install unknown apps** permission for the browser or file manager used to open the APK.
- Verify the downloaded file against `SHA256SUMS.txt` before installation.

## Privacy

There is no sign-in, advertising, analytics, or developer telemetry. Results and custom network profiles remain on the device. Speed-test traffic uses generated payloads and does not contain user files.
